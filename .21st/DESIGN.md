# MODO Design Context

MODO is a professional fashion-retail planning workspace. It should feel calm,
precise, and editorial without resembling a lifestyle shop or a generic SaaS
dashboard.

## Direction

- Graphite and porcelain form the neutral foundation.
- Mineral blue is the single interactive accent.
- Green, amber, and red are reserved for semantic data states.
- Photography brings fashion context to Overview and authentication surfaces.
- Dense work surfaces use spacing, typography, and rules before card elevation.
- Motion communicates hierarchy, feedback, or state changes only.

## Layout

- Desktop uses a persistent 248px sidebar.
- Mobile uses a 64px top bar and an explicit navigation drawer.
- Data pages remain dense and task-oriented.
- Overview provides current context, attention items, and a route back into work.

## Accessibility

- Interactive targets are at least 44px where space permits.
- Focus rings are always visible.
- Color is never the only carrier of status.
- Motion respects `prefers-reduced-motion`.
